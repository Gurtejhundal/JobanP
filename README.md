# Jobanpreet Singh — Portfolio

An editorial React portfolio with a cinematic identity reveal, spatial portrait and card depth, scroll-led transitions, responsive layouts, and reduced-motion fallbacks.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm run build
npm run test:sites
```

Portfolio content is centralized in `src/portfolioData.js`. Education, work history, CV, and contact links intentionally remain neutral until Jobanpreet's verified details are supplied.
